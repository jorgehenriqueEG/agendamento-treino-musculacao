# agendamento-treino-musculacao

## Descrição do Problema
Gerar uma lista de dias de treino para uma semana, garantindo que cada exercício apareça apenas uma vez por dia e respeitando o limite máximo de exercícios por sessão.

## Requisitos
- Usar um array de exercícios disponíveis.
- Evitar exercícios repetidos no mesmo dia.
- Limitar cada dia a no máximo 3 exercícios.

## Exemplo de Uso
Entrada: 3 dias de treino, 5 exercícios disponíveis.

Saída:
["Dumbbell Curl, Leg Press, Bench Press", "Squat, Row, Push-up", "Deadlift, Shoulder Press, Lunge"]
